# Glossary and Resources

## Domain Terms

| Term | Definition |
|------|------------|
| **Risk** | A potential event or condition that could negatively impact an engagement |
| **Severity** | Impact level if the risk materializes (critical, high, medium, low) |
| **Likelihood** | Probability of the risk materializing (almost_certain through rare) |
| **Risk Score** | Calculated value: severity_weight x likelihood_weight |
| **Risk Register** | Structured YAML log of all identified risks per node |
| **Mitigation** | Action taken to reduce the probability or impact of a risk |
| **Pattern** | Recurring risk type detected across multiple accounts |
| **Escalation** | Notification to higher authority when risk severity or pattern thresholds are breached |
| **Materialized** | A risk that has become an actual issue |

## Risk Lifecycle States

Identified → Assessed → Mitigating → Monitoring → Mitigated | Accepted | Materialized

## External Resources

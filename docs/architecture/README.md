# Architecture

System design documentation covering agents, playbooks, and core infrastructure. The platform implements a 196-agent governance model for strategic account management, organized into 25 team directories spanning sales, architecture, intelligence, delivery, specialists, governance, and leadership. Roles with complex processes (AE, SA, VE, and others) decompose into sub-agents via holonic decomposition.
